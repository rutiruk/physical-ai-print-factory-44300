## 学んだ工程と一次資料（2026-11-01確認）

1. DNP「版を作る」: 入稿・校正・校了、面付け、CMYK刷版。折った後のページ順を面付け段階で決める。https://www.dnp.co.jp/media/detail/20168683_1563.html
2. DNP「印刷する」: 輪転は巻取、枚葉はカット紙。輪転の熱風乾燥・冷却を枚葉UVに流用しない。試し刷りで校了紙と比較し、本刷り中にも品質確認。https://www.dnp.co.jp/media/detail/20169183_1563.html
3. DNP「製本する」: 表紙の前断裁、折丁の丁合、綴じ、三方断裁、結束。中綴じは折丁を開いて入れ子にする。無線綴じの閉じた折丁の積み重ねと区別。給紙・補充・紙揃えにも作業が残る。https://www.dnp.co.jp/media/detail/20169338_1563.html
4. JAGATポストプレス: 綴じ方・折り方が面付けを決める。背丁・背標、くわえ・針側、折り、三方仕上げ裁ち。https://www.jagat.or.jp/cat5/dtp/exam/curriculum/3-7
5. KOMORI H-UV: UV硬化で速乾し後加工へ渡せる。すべての印刷を一定時間の自然乾燥としない。https://www.komori.com/ja/jp/information/news/2019/0130_217.html
6. Horizon STITCHLINER: 平らな刷本の丁合→筋入れ・折り→鞍掛け中綴じ→三方断裁という別構成もある。今回の独立折り機→折丁丁合とは混在させない。給紙順のバーコード確認、丁合ミス排出という品質ゲートを参考にする。https://www.horizon.co.jp/products/catalog/j_pdf/j001st/01sl_pdf/icestitchilinermarkiv_j.pdf

特定機種の完全なデジタルツインではない。以下の寸法・冊数・処理時間・機械配置は課題用に設計する値であり、メーカー仕様を再現したという主張はしない。

## 製品と採用工程（実装者判断）

- 製品: A4縦・左綴じ・16ページ・共紙中綴じ冊子100冊、100g/m²。
- 原紙: SRA3 450×320mm、4種類の4ページ面付けフォーム、各100枚。表裏印刷で合計400枚。4種類を各1枚使い1冊。
- 面付け例: F1 表16|1 裏2|15、F2 表14|3 裏4|13、F3 表12|5 裏6|11、F4 表10|7 裏8|9。ページの天地回転や反転方式はこの例の設定に従う。
- 工程: 入稿/校了・面付け承認 → 枚葉両面UV印刷 → UV硬化完了信号・検査承認 → 紙揃え/向き確認 → 独立折り → 折丁丁合（F1外側〜F4内側）→ 中綴じ → 三方断裁 → 梱包。
- 平判450×320→折り225×320→仕上げ210×297mm。背は切らず小口15mm、天地各11.5mmを除く課題設定。3mmの塗り足しと原紙全体の余白を同一視しない。
- AMRは100枚束を搬送する。吸着で未結束の100枚を一度に持ち上げない。機械ドックへの水平移載をローダー/コンベアで近似する。紙束は剛体束で、単葉分離・静電気・摩擦給紙は未モデル化。
- 印刷ローラー、インキ転移、UV反応、折りローラー、針金貫通、断裁刃の切断物理は工程モデル。剛体の搬送・接触・向き・支持はGenesis。紙の状態は束、折丁束、冊子束として可視化し、内部処理を物理的に再現したとは呼ばない。

## 必須の状態と禁止条件

ジョブ/版revision、フォーム番号、ページ集合、表裏印刷、硬化、検査、紙揃え、折り、数量、寸法、向き、現在地を追跡する。印刷開始には校了と面付け承認が必要。裏面未印刷、硬化未確認、不良判定、未揃え、誤方向の束は折りへ渡さない。異ジョブ/異版/重複/不足/枚数不一致の折丁は綴じへ渡さない。未綴じの冊子を三方断裁しない。仕上げ寸法と枚数・紙の質量収支も採点する。
