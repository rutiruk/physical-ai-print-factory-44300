# Jeff非同期印刷工場の実装計画

> REQUIRED: superpowers:executing-plans。ユーザーは実装続行を指示済み。

1. Jeff公開checkpointの画像・選択推論を独立環境で検証し、workerを作る（担当jeff_runtime）。
2. ViNTとNoMaDの公開重みをstrict loadし、画像→waypointを実GPU推論する（担当navigation_models）。
3. ジョブ到着・設備予約・加工タイマ・搬送割当・世代管理をテスト先行で作る（root）。
4. Genesisの前方カメラ・目標画像と各AMRの方策を結び、接触・進行を検証する（root）。
5. 俯瞰映像、到着、選択、担当・積載物、工程を同時刻で描画する（root）。
6. 実通し実行と従来参照を記録。成功範囲・失敗・所要時間を確認し、課題要件と提出物を更新する。

既存の提出用動画/PDF/ZIPは新構成の実行成功を確認するまで上書きしない。

## 実施記録

Jeff 2B v1.2、ViNT、NoMaDを独立環境で実GPU推論。モデル・コードrevisionとSHA256を固定した。0.8Bの画像判断失敗、全体画像を重ねた作業選択の待機、移動モデルの疎な目標・逸脱・ドッキング失敗を保存し、画像判断/テキスト作業選択の分離、密な画像目標、0.40mの向き優先ドック、Jeffが選ぶ最大4回の再試行を実装した。

ジョブの白紙割当、物理カセット占有、独立した3つの仕上げ前置場、共有橋・待機位置・不変観測スナップショットを検証。4p品は二つ折りリーフレットとして綴じを省略し、8p冊子のみ中綴じする。純粋テスト61件通過。単独の実NoMaD接近/荷下ろしと、記録された近傍位置からのドック/荷下ろしも成功。

現行通し実行はoutput/jeff_factory/jeff/result.json。実際にJeffが逸脱後の再試行を選び、搬送を再開した。全ジョブ完成・全16移載支持確認、動画全フレーム/PDF全ページの検証、ソースZIP作成は通し実行後に確定する。提出IDはrutirukt。YouTube/GitHub/OmniCampusの公開提出は未実施。ルール参照は制御修正時の中断記録であり、AIとの性能比較に使わない。

最終通し実行は732.37 SIM秒で成功、16/16移載が支持条件を満たした。冊子Aは540.05秒、リーフレットBは359.80秒（9.80秒遅れ）、Cは732.36秒で完成。Jeff20判断、ViNT345推論、NoMaD314推論、Jeffによる再試行1回。成果物検証はエラーなし。動画143.35秒、20fps、2867フレームすべて復号、全学習済み移動・全移載を保持。PDF3ページを描画・目視確認済み。
